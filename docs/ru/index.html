Отключение и восстановление Defender для Windows 10/11

Скажи «bye» Microsoft Defender — и верни его в любой момент. Один клик — чтобы выключить защиту в реальном времени, один клик — чтобы включить обратно. Без консольных окон и угадывания.

⬇ Скачать DefenderBye.exe Исходный код на GitHub

Windows 10 (22H2) и Windows 11, x64 · Бесплатно, открытый код (MIT) · SHA-256 публикуется с каждым релизом

Две большие кнопки

«Отключить Defender» или «Восстановить Defender». Приложение само определяет текущее состояние и включает только нужную кнопку.

Действительно работает

Меняет те же политики, что используются в корпоративных Group Policy / Intune, включая облачную отчётность и плановое сканирование — а не только переключатель в «Безопасности Windows».

Обратимо

Каждое изменение сохраняется в снапшот перед применением. Восстановление точно возвращает прежние значения или откатывает к стандартным настройкам Windows.

Честный статус

Показывает «Защищён» / «Отключён» / «Частично отключён» и прямо говорит, если Windows Update или Tamper Protection что-то включили обратно.

Тестовый прогон (dry run)

Показывает, что именно изменится, без реального применения.

Брандмауэр не трогается — никогда

Брандмауэр Windows в жёстком списке запрета, закреплённом в коде и проверяемом тестом. DefenderBye не может его тронуть в принципе.

  1. Проверяет права администратора (предложит перезапуск с повышением, если их нет).
  2. Проверяет Tamper Protection. Если включена — показывает, как выключить её вручную. DefenderBye никогда не пытается её обойти.
  3. Отключение: сохраняет снапшот всех значений реестра/служб перед изменением, затем применяет шаги по порядку.
  4. Восстановление: возвращает значения из снапшота или, если его нет, — к стандартным настройкам Windows.
  5. Предлагает перезагрузку, если она нужна для применения изменений.
  • Каждое изменяемое значение сохраняется заранее, поэтому восстановление точное.
  • Брандмауэр Windows (mpssvc, BFE, SharedAccess и связанные политики) никогда не трогается — это закреплено в коде и проверяется тестом, который ломает сборку при нарушении.
  • Нет обхода Tamper Protection, нет удаления Defender или приложения «Безопасность Windows» в этой версии.
  • Нет сетевых запросов, нет телеметрии, нет автообновления с загрузкой исполняемых файлов, нет записей автозагрузки.
  • Windows Update или Tamper Protection могут незаметно включить Defender обратно. DefenderBye определяет это при следующем запуске и честно показывает, а не делает вид, что всё ещё отключено.
Антивирус помечает DefenderBye.exe. Это вирус?

Нет — это ожидаемо для любого инструмента, способного выключать защиту самого антивируса. Сверьте опубликованный SHA-256 с файлом SHA256SUMS.txt в релизе или соберите приложение из исходников самостоятельно — код полностью открыт.

Я отключил защиту, но Defender включился сам.

Проверьте Tamper Protection (Безопасность Windows → Защита от вирусов и угроз → Управление настройками) и недавние обновления Windows — оба могут откатывать изменения политик. DefenderBye покажет «Частично отключён» или «Защищён», а не сделает вид, что всё ещё выключено.

Это тронет мой брандмауэр?

Нет, никогда. См. раздел «Безопасность» выше.

Он полностью удаляет Defender?

Нет. Эта версия только отключает/включает защиту в реальном времени и связанные настройки через поддерживаемые, обратимые механизмы. Ничего не удаляется.
