Defender Remover & Restore GUI for Windows 10/11

Say bye to Microsoft Defender — and bring it back anytime. One click to disable real-time protection, one click to restore it. No console windows, no guesswork.

Windows 10 (22H2) & Windows 11, x64 · Free & open source (MIT) · SHA-256 published with every release

Two big buttons

Disable Defender, or Restore Defender. The app detects the current state and enables only the button that makes sense.

Actually sticks

Flips the same policy keys enterprise Group Policy / Intune use, including cloud reporting and scheduled scans — not just the toggle in Windows Security.

Reversible

Every change is snapshotted before it's made. Restore replays the snapshot exactly, or falls back to Windows defaults.

Honest status

Shows Protected / Disabled / Partially disabled, and tells you plainly if Windows Update or Tamper Protection re-enabled something.

Dry run

Preview exactly what would change before touching anything.

Firewall untouched — always

The Windows Firewall is on a hard refuse-list enforced by code and a unit test. DefenderBye cannot touch it, ever.

  1. Checks you're running as Administrator (asks to relaunch elevated if not).
  2. Detects Tamper Protection. If it's on, shows you how to turn it off yourself — DefenderBye never tries to bypass it.
  3. Disable: snapshots every registry value / service start type it's about to change, then applies each step in order.
  4. Restore: replays that snapshot in reverse, or restores Windows defaults if there is no snapshot.
  5. Prompts you to reboot when a change needs it to fully take effect.
  • Every value DefenderBye changes is captured first, so Restore is exact.
  • The Windows Firewall (mpssvc, BFE, SharedAccess and related policy keys) is never touched — enforced in code with a test that fails the build if that is ever violated.
  • No Tamper Protection bypass, no uninstall/deep-remove of Defender or the Security app in this release.
  • No network calls, no telemetry, no auto-update that downloads executables, no persistence or startup entries.
  • Windows Update or Tamper Protection can re-enable Defender behind your back. DefenderBye detects this on next launch and shows it honestly instead of pretending everything is still off.
My antivirus flags DefenderBye.exe. Is it malware?

No — this is expected for any tool that can switch off an antivirus's own protections. Verify the published SHA-256 against SHA256SUMS.txt on the release, or build it yourself from source; the code is fully open.

I disabled it, but Defender turned itself back on.

Check Tamper Protection (Windows Security → Virus & threat protection → Manage settings) and recent Windows Updates — both can revert policy changes. DefenderBye will show "Partially disabled" or "Protected" instead of pretending it's still off.

Will this touch my firewall?

No, never. See Safety above.

Does it remove Microsoft Defender entirely?

No. This build only disables/re-enables real-time protection and related settings through supported, reversible mechanisms. It does not uninstall anything.
